Run my testbench

  
Type a character. A UART transmitter frames it (8N1, LSB first), a receiver samples it mid-bit, and a scoreboard checks the result. Then break it.

  
Waiting for a transmit.






  
Watch my histogram engine

  
Pixels stream in, each value becomes a memory address, and the engine reads, increments and writes back. It is the same idea as my CAIR histogram project, shrunk to a 16x16 sketch. Switch images and watch the shape change.

  






  
Add in hardware

  
Flip the switches. A 4-bit ripple-carry adder computes the sum, and the carry travels through the full adders one stage at a time, which is exactly why it is slow.

  






  
Break my assertion

  
Assertions (SVA) are one of my top skills. This property says: when req rises, ack must arrive within 1 to 3 cycles. Click the cells to edit the waveform and try to break it.

  
assert property (@(posedge clk) $rose(req) |-> ##[1:3] ack);
